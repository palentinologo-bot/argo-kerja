# Argo Kerja — PWA

Versi pertama aplikasi "argo taksi, tapi waktu kerja".

Default:
- Senin–Jumat
- 08:30–17:30
- Istirahat 12:00–13:00
- Upah ¥1,050/jam

Bisa diubah dari tombol ⚙︎.

## Cara paling mudah di Windows
File ini adalah PWA statis. Agar bisa dipasang ke iPhone sebagai aplikasi Home Screen, file perlu di-host melalui HTTPS (misalnya GitHub Pages).

1. Buat repository GitHub baru.
2. Upload semua file dalam folder ini.
3. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → main/root.
4. Buka URL HTTPS Pages tersebut di Safari pada iPhone.
5. Tekan Share → Add to Home Screen.

Aplikasi menghitung berdasarkan timestamp saat ini, jadi tidak perlu stopwatch benar-benar hidup di background.
